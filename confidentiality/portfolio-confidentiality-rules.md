# Public Portfolio Confidentiality Rules

1. Do not publish client-owned source code without explicit permission.
2. Do not publish real credentials, API keys, server details or environment files.
3. Do not publish identifiable customer, employee, borrower, supplier or student information.
4. Do not publish confidential screenshots or internal documents without permission.
5. Use fictional or anonymised data for demonstrations.
6. Describe client work at a high level only where the experience can be discussed professionally.
7. Keep public examples independent from proprietary production implementations.
8. Re-check repository history before changing any private client repository to public.
