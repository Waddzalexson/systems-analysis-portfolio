# Changelog

## v2.0 - Presentation-ready concept

- Simplified the parent-facing interface and removed repetitive prototype notices.
- Expanded the synthetic catalogue from three to eight schools.
- Added saved schools, comparisons and detailed school views.
- Added application checklist previews with explicit no-submission behaviour.
- Improved natural-language-inspired search, filters, sorting, empty states and question guide.
- Preserved explicit handling of unknown fees and deadlines.
- Added an optional Python backend and a disabled-by-default server-side LLM adapter.
- Added Python API tests, retrieval tests and responsive browser smoke tests.
- Updated documentation to separate public demo capabilities from optional backend capabilities.
